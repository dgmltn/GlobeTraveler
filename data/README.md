# :data

Implementations of the `:domain` repository contracts plus persistence and bundled
map-pack assets.

**Contains:** Room 3 database (`GlobeDatabase`, `VisitDao`, `VisitEntity`),
`VisitRepositoryImpl`, `MapPackRepositoryImpl` (reads `composeResources/files/`
descriptor + GeoJSON via `Res.readBytes`), `IpLocationRepositoryImpl` (geojs.io IP
geolocation: polls the bare-IP endpoint, geo lookup only on IP change), `dataModule()`
Koin module (including the shared Ktor `HttpClient`), and per-platform database
builders (android / ios / jvm).

**Depends on:** `:domain`, Room 3 + bundled SQLite, Koin, Ktor client (okhttp / darwin /
java engines), kotlinx-serialization, Compose components-resources (resource loading
only — no UI).

**Assets:** `src/commonMain/composeResources/files/us-states.{geojson,descriptor.json}`,
generated by `scripts/build-mappack.py` — do not edit by hand.

**Tests:** `./gradlew :data:jvmTest` (real in-memory Room via bundled driver).
